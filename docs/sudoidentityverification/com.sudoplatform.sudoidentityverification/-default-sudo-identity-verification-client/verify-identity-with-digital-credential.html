verifyIdentityWithDigitalCredential

@RequiresApi(value = 28)
open suspend override fun verifyIdentityWithDigitalCredential(activity: Activity): DigitalCredentialVerificationOutcome

Verifies identity using a digital credential, such as a mobile driver's licence, held in a wallet on the device. Requests a presentation from the service, shows the Credential Manager credential selector so the user can choose a credential, then submits the presentation to the service for verification.

A successful verification completes identity verification on its own; the knowledge of PII step performed by verifyIdentity is not required.

Where the service requires a residential address and the presented credential carries none, such as a Google ID pass, the result is DigitalCredentialVerificationOutcome.ResidentialAddressRequired. Collect the user's address and pass the result to completeDigitalCredentialVerification.

The service only accepts presentations from apps whose signing certificate is in its list of permitted origins.

Return

A DigitalCredentialVerificationOutcome verification outcome.

Parameters

activity

Activity The activity the credential selector is shown over.

Throws

SudoIdentityVerificationException.DigitalCredentialCancelledException

if the user dismissed the credential selector.

SudoIdentityVerificationException.NoDigitalCredentialException

if no credential on the device satisfies the request.

SudoIdentityVerificationException.DigitalCredentialUnsupportedException

if the device cannot request digital credentials.

SudoIdentityVerificationException.DigitalCredentialRequestExpiredException

if the request expired before a credential was presented.

SudoIdentityVerificationException.DigitalCredentialVerificationFailedException

if the presented credential was rejected as malformed or not authentic.

SudoIdentityVerificationException.DigitalCredentialIssuerNotTrustedException

if the presented credential's issuer is not trusted.

SudoIdentityVerificationException.DigitalCredentialNotAcceptedException

if the presented credential is not of an accepted type.

SudoIdentityVerificationException.DigitalCredentialNoLongerValidException

if the presented credential, or the certificate that signed it, has expired or been revoked.
